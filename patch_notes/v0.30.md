### v0.30.0

#### UMAPINFO / MAPINFO
- Bumped UMAPINFO support to revision 3
  - Support for Heretic
    - Only missing `endcast`
  - Allow for 10 episodes instead of 8
  - Added `jumping`, `crouching` and `freeaim` keywords
  - Added `endpalette` keyword
- Internal rework of how some UMAPINFO properties are handled
- Removed ZDoom MAPINFO support

#### UDMF
- Added support for base spec UDMF namespaces
  - `doom`, `heretic` and `hexen`
- Added `Line Horizon` special
  - Currently only works with the Software renderer
- Fixed `Door_Raise` special not being able to close while open
- s
#### New Features
- Added mouse navigation to menus (@El-Juancho)
  - With much added care for the little details
- Added string values for `-complevel`
  - `vanilla`, `boom`, `mbf` and `mbf21`
- Added support for optional menu and intermission sounds
- Added support for `TrueColor` OpenGL light fade (@JNechaevsky and @pvictress)
- Added "click to advance" to Heretic textscreens
- Added `SWITCHES` support for Heretic
- Added `Fix Shallow Floor View Bob Jolt` option (@bangstk)
  - Smooths the view bob when running across shallow floors
- Added `Show Line Traces` option (@feos)
  - Shows hitscan line traces in the automap
- Added `spawn_rel` console command
- Added `target.get_target` console command
- Added Dehacked custom secret message
  - `HUSTR_SECRETFOUND`
- Added BEX mnemonics for beta pickup sprites

#### Miscellaneous
- Added `-loadgame` back
- Added icon for GNOME environments (@electricbrass)
- Added interpolation for dropped items
- Added kerning to Raven messages to match vanilla
- Allow `ANIMATED` and `SWITCHES` lumps in IWADs
- Allow Death Use `Nothing` in demos
- Allow changing translucency option in strict mode
  - Vanilla complevels force opaque anyway
- Allow toggling fullscreen with `alt + enter` (@JNechaevsky)
- Do not treat `super` key as `alt`
- Do not read patches that are outside the `PNAMES` table
- Disabled screen melt in Heretic
- Optimized vanilla teleport destination search
  - Fixes Oversaturation MAP04 lag
- Restrict joystick movement inputs to even numbers (@ceski)
- Switch mouse buttons 2 and 3
- Ensure integer parsing in config flags does not discard data (@yrriban)
- Name the screenshots "dsda" instead of the generic "doom"\
  - Increased screenshots number limit
- Replace Nuked-OPL3 with Nuked-OPL3-fast
  - Using 1.8-fast.3 (@tgies)

#### Compiling
- The macOS build is now Universal and Static
- The Windows build now works in Windows 7
- Fixed macOS failed build due to SDL2 now using SDL3 with a compatibility layer
- Fixed newer `ZLIB` versions causing compilation error
- Added `libsndfile` to the building instructions
